# Surface brief — Desktop evidence desk

- Mode: Operate.
- Audience: the local laboratory operator.
- Job: see what is known, what is merely detected and what exact evidence blocks the next gate.
- Primary action: select a work area, inspect evidence and launch only reversible local actions.
- Proof: real node reports, snapshot hashes, strategy runs and phase-gate requirements.
- Constraints: no direct filesystem, SQLite, vault, shell or secret access from React; all
  illustrative content says `DEMOSTRACIÓN`.
- Direction: comparative assay plate with evidence stamps and a contextual gate inspector.
- Memorable moment: the comparison sheet makes missing evidence spatially obvious without
  collapsing trade-offs into one score.
- Open decision: primary operator identity remains an explicit product assumption.
