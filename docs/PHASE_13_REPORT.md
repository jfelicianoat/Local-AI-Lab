# Fase 13 — Strategy Selector

El selector requiere un mínimo declarado de casos comparables y, por defecto, un veredicto
formal de Model Drift. Aplica restricciones de privacidad, latencia y coste y después usa
un orden lexicográfico de métricas nombradas por el usuario. Devuelve referencias de
evidencia y una advertencia explícita de incertidumbre; nunca convierte la recomendación en
certeza.
