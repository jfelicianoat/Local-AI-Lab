# Fase 12 — Strategy Comparison

La comparación presenta calidad, retrieval, coste, latencia, memoria, privacidad y
complejidad como dimensiones separadas. Un coste desconocido se mantiene como `null` con
procedencia y estado; nunca se convierte en cero. No existe score global.

El escritorio dispone de una vista autenticada para los registros de experimentos y
comparaciones. Los valores reales aparecerán únicamente al registrar artefactos ejecutados.
